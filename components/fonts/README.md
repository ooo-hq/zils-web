# Zils wordmark font

`grenze-gotisch-zils.woff2` contains the four glyphs in **Zils**, set in
Grenze Gotisch Semibold (600) by Omnibus-Type. The font is self-hosted and used
only by `ZilsWordmark`; body and interface typography remain IBM Plex.

- [Font source](https://github.com/google/fonts/tree/main/ofl/grenzegotisch)
- [Google Fonts subset](https://fonts.googleapis.com/css2?family=Grenze+Gotisch:wght@600&text=Zils&display=swap)
- License: SIL Open Font License 1.1, reproduced in `OFL.txt`.

The site icons use the exact uppercase Z outline from this same bundled font,
centered on a dark square. `app/icon.svg` is the vector source;
`app/favicon.ico` contains 16, 32, and 48 pixel copies, and
`app/apple-icon.png` is an opaque 180 pixel home-screen icon.
These static assets need no font request or runtime image generation.
